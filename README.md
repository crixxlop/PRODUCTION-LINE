# PRODUCTION-LINE
Definición del problema

¿Qué ventajas representa un sistema mecánico/automatizado de banda clasificadora de productos frente al trabajo humano existente en la empresa? Existen varios factores que incentivan una transición de metodología de clasificación de productos de trabajo humano a la automatización, algunos de los más evidentes son:

Eficiencia al momento de clasificar los productos
Menor tasa de errores al clasificar
Mantenimiento centralizado en las máquinas
Facilidad en la creación de un plan de escalabilidad a largo plazo
Reducción de costos de operación, clasificación y manufactura de los productos.
La correcta implementación de estos factores permitirá obtener beneficios a nivel operativo y financiero, sin comprometer la continuidad de los procesos de producción.

¿Cómo se llevaría a cabo el despliegue del sistema?

Dado el contexto empresarial actual se contempla una prueba piloto manteniendo el personal actual para llevar a cabo un análisis de los resultados antes y después de la implementación del nuevo sistema, dados los resultados se procederá a una migración progresiva que resultará en un sistema completamente automatizado, con intervención humana puntual (supervisión y mantenimientos) lo que permitirá garantizar el funcionamiento ininterrumpido de la producción.

Como una solución TI (software + Hardware (controladores y sensores)) Podría solucionar (aportar) el problema
La solución de TI propuesta integra hardware (sensores y controladores) y software (lógica de clasificación y gestión de datos) en un sistema inteligente automatizado capaz de percibir, decidir y actuar de forma autónoma sobre el proceso de clasificación de productos, sustituyendo la intervención humana en tareas repetitivas y propensas a error, mientras se genera información valiosa para la mejora continua del proceso productivo.
